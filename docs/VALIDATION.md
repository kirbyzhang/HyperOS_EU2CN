# OS318.0.1 验证范围

## 当前候选：后台直连与异步保存修复

- 新机为小米 17（pudding）、HyperOS EU OS318、Android 16，KernelSU 3.3.1 / kernel32680 / UAPI5。
- 已确认旧程序会在异步保存落盘前停止，且 Greezer 会缓存发给后台 KernelSU 的广播。
- 持久化修复后，同批完成剩余 20 个 UID 组；47 条最终记录中的其余 27 条逐字节不变，Root 授权和全局默认保持。该批真实写入使用旧广播传输，期间 KernelSU 临时位于前台。
- 新 Provider 直连在管理器冷启动、同进程重复运行及 CACHED_EMPTY 状态通过后台读取；幂等 apply 为 writes=0、错误预期状态拒绝、配置字节不变。Shell UID 访问被不导出权限拒绝，未打开管理器 Activity。
- 正式兼容层和辅助 DEX 已热更新到新机；20 项 LSPosed 作用域保留，包括 KernelSU。计划待处理为 0。
- 9 项主机 unittest 通过，其中持久化测试覆盖必须唤醒才保存、超过旧等待时限、临时截断、全局/Root/额外 UID 变化、超时和权限拒绝。APK/DEX 构建、原证书签名、488 项载荷哈希和 ZIP CRC 检查通过，其余 52 个 APK 未变。

用户完整重启后的只读复验已通过：

- boot ID 已变化；47 条配置与重启前逐字节一致，新增 20 组例外全部保留。
- 20 项 LSPosed 作用域不变；正式兼容层、活动辅助 DEX 与修复版哈希相同，模块已启用。
- 计划待处理 0 组；Provider 后台读取成功、writes=0，前台页面保持，配置字节不变。
- 8 个模块应用的 10 个现有进程共 129 项 APK/原生库哈希匹配；电话 UID1001 进程内的语音代理 APK 哈希另已匹配。现有独立应用更新保持。

当前新传输的实际非幂等写入及新 ZIP 整包安装仍未验证。ZIP 内 README 是打包时的快照；本文件补充后续实机结果，ZIP/APK 字节未因本次复验而改变。
