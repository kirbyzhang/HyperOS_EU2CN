# HyperOS_EU2CN

为 HyperOS EU 按需补充国行应用与功能，提供桌面搜索、小组件、天气、主题、电话和短信等兼容设置。

项目由 **KernelSU 模块**和 **LSPosed 兼容层**组成：模块提供所选应用及资源，兼容层提供适配开关、状态检查和维护入口。

**当前版本：OS318.0.1 · 内部版本号：31801**

## 适用环境

| 项目 | 已有验证环境 |
| --- | --- |
| 机型 | 小米 17（pudding） |
| 系统 | HyperOS EU OS3.0.318.0，Android 16 |
| Root 与挂载 | KernelSU，Hybrid Mount / Magic Mount 类挂载后端 |
| Hook 环境 | Zygisk Next + LSPosed |
| 国行应用来源基线 | 主要为 OS3.0.319.0，部分应用使用独立更新版本 |

本项目没有强制机型限制；其他机型、ROM、Root 方案和挂载组合仍需单独验证。兼容层须在 LSPosed 中启用并设置作用域，仅安装 APK 不会启用 Hook。

**更新系统前先停用本模块，并重新确认新 ROM 的兼容性。**

## 功能一览

安装时按需选择组件，安装器只解压选中的内容。

| 类别 | 可选内容 |
| --- | --- |
| 常用应用 | 应用商店、日历、天气、音乐、录音机、便签 |
| 相册与主题 | 国行相册及编辑组件、主题管理器、独立主题商店入口、锁屏画报 |
| 桌面 | 国行负一屏、上滑国行搜索、小米小组件、Google 入口兼容 |
| 小爱与内容识别 | 小爱及配套组件、传送门、内容识别 |
| 电话与短信 | 国行短信、黄页、AI 通话、新通话组件、视频通话美颜相关设置 |
| 钱包与互联 | 钱包配套组件、全球上网 / 虚拟 SIM、CarWith、数字车钥匙 |
| 输入与外观 | 小米版搜狗、安全键盘、Gboard 主题、字体 |
| 系统兼容 | 密码管理入口、智能应用助手、双开、通知兼容、推送相关选项 |

兼容层还提供国行搜索、天气、主题、黄页、电话和短信的应用兼容开关。模块安装选项在界面中显示为状态，修改安装组件需要重新安装模块。

完整 CN XMSF、FCM 后台兼容和旧国际环境总开关须单独选择，普通「一键全选」不会开启。局部双开安全和桌面 Google 环境兼容可独立使用，具体依赖见 [配置说明](docs/CONFIGURATION.md)。

## 安装与启用

1. 备份重要数据，在 KernelSU 中选择模块 ZIP，按提示选择所需功能；需要 Hook 功能时同时选择兼容层。
2. 安装后通过**系统电源菜单完整重启**。
3. 如已选择兼容层，在 LSPosed 中启用 **HyperOS_EU2CN 兼容层**并勾选推荐作用域，其中包括 **KernelSU**。调整后重新启动 KernelSU 管理器。
4. 如果 KernelSU 开启了「默认卸载模块」，进入本模块的「操作」，按**音量+**后台补齐挂载例外；未安装或启用兼容层时请手动设置例外。
5. 完成作用域和挂载例外设置后，再完整重启一次，打开所选应用确认。

首次安装时，如已通过完整模块安装兼容层，无需重复安装独立 APK。如果此前单独安装过兼容层，升级模块时也请覆盖安装对应版本 APK，保留数据和作用域，避免旧独立版本覆盖模块版本。

应用协议、隐私提示和权限请求由用户自行选择。兼容开关调整后，重新打开对应应用；涉及电话或首次启用作用域时完整重启。

### 使用配置文件安装

从 [配置模板](config/EU2CN_Config.ini) 复制一份，命名为 `EU2CN_Config.ini`，放到手机的 `Download` 目录。将所需组件设为 `true`，再安装 ZIP。例如：

```ini
Weather=true
CnSearch=true
ToolsBox=true
```

以上示例选择天气、国行搜索和兼容层；其余选项请保留完整模板中的配置。`ToolsBox` 为兼容层安装开关，其附属 Hook 选项仅在安装兼容层后生效。

安装器优先读取 `Download/EU2CN_Config.ini`，没有此文件时兼容读取旧名 `PuddingEULocalization.ini`。没有外部配置且检测到旧模块时，会询问是否沿用：音量+沿用，8 秒无操作进入重新选择。

公开模板的安装组件默认关闭，部分兼容子项保留原有默认值；不选择任何组件会得到空配置模块。安装前请确认 Download 中的文件是你希望使用的那份。完整选项与依赖见 [配置说明](docs/CONFIGURATION.md)。

## KernelSU 挂载例外

KernelSU 的「卸载模块」可能使应用无法读取模块提供的 APK，表现为闪退或资源错误。可以保留全局默认，为需要的应用设置「自定义 → 关闭卸载模块」，无需向这些系统应用授予 Root。

模块「操作」提供两个入口：

- **音量+**：通过兼容层在后台调用 KernelSU 自身的保存接口，补齐所需挂载例外。
- **音量- 或 8 秒无操作**：查看诊断及最近结果。

后台方式需要兼容层的 KernelSU 作用域，无需保持亮屏或停留在管理器页面。运行期间不要同时修改 KernelSU 配置或更新管理器。

辅助程序按实际安装组件和当前 UID 生成名单，合并共享 UID，保留全局默认、已有 Root 授权及无关配置。保存后会等待落盘确认；接口不兼容、配置变化或确认失败时停止并报告进度。它不会自动重启或设置 LSPosed。

## 卸载与恢复

在 KernelSU 中卸载模块后完整重启。模块卸载脚本不主动清除应用数据，但系统移除或切换系统应用时仍可能处理相关数据，请提前备份重要内容。独立安装的 APK、手动应用更新和手动调整的 Root 设置需分别管理。

如果无法进入系统，可在 Recovery 中创建以下空文件以停用模块，再启动系统：

```text
/data/adb/modules/HyperOS_EU2CN/disable
```
