# HyperOS_EU2CN

为 HyperOS EU 系统按需补充国行应用和功能，并提供桌面搜索、小组件、天气、主题、电话和短信等兼容设置。

**当前版本：OS318.0.1**。模块和兼容层均使用此版本名，内部版本号为 `31801`。

## 适用环境

- 功能基线已在小米 17（pudding）、HyperOS EU OS3.0.318.0、Android 16 上验证。
- 已测试的 Root 环境是 KernelSU、Hybrid Mount / Magic Mount 类挂载后端，以及 Zygisk Next + LSPosed。
- 兼容层需要在 LSPosed 中启用；只安装 APK 不会自动启用这些兼容功能。
- 国行应用主要来自 OS319。本项目没有强制机型限制，其他机型、ROM 和 Root 组合仍需单独验证。

更新系统前先停用本模块，新 ROM 需要重新核对兼容性。不要与旧版钱包引导模块同时启用。

## 安装与启用

1. 在 KernelSU 中选择模块 ZIP 安装，按提示选择所需功能。
2. 安装完成后，使用**系统电源菜单完整重启**。
3. 如果选择了兼容层，在 LSPosed 中启用 **HyperOS_EU2CN 兼容层**，勾选推荐作用域，其中包括 **KernelSU**。调整作用域后重新启动 KernelSU 管理器。
4. 如果 KernelSU 开启了“默认卸载模块”，进入本模块的“操作”，按**音量+**后台补齐挂载例外。无需保持亮屏或停留在管理器页面；运行期间不要同时修改 KernelSU 配置。未选择兼容层时请手动设置例外。
5. 完成挂载例外和 LSPosed 设置后，再完整重启一次，打开所选应用确认。

首次安装时，模块 ZIP 已包含兼容层，无需重复安装独立 APK。如果曾单独安装兼容层，升级模块时也请覆盖安装本版本附带的兼容层 APK，保留数据与作用域，防止旧独立版本继续覆盖模块版本。所有应用的协议、隐私和权限提示均由你自行选择。

### 使用配置文件安装

把模板命名为 `EU2CN_Config.ini`，放到手机的 `Download` 目录，再安装 ZIP。将需要的项目设为 `true`，其余保留 `false`；兼容层对应的键是 `ToolsBox`。

安装器会**优先读取 Download 中的 `EU2CN_Config.ini`**；如果没有新文件名，也兼容读取旧名 `PuddingEULocalization.ini`。没有外部配置时，检测到旧模块会询问是否沿用：按音量+沿用；8 秒无操作会进入重新选择。安装前请先确认外部配置是你希望使用的那份。

公开模板的安装组件默认关闭；局部双开安全与桌面国际环境兼容保留原有默认值。**不需要为了使用这些局部功能而开启旧国际环境总开关。** 配置依赖和每个国际环境选项的范围见 [配置说明](docs/CONFIGURATION.md)。

## KernelSU 挂载例外

开启“卸载模块”的应用可能读不到模块提供的 APK，表现为闪退或资源错误。可以保持全局默认开启，为需要的应用使用“自定义 → 关闭卸载模块”；无需给这些系统应用授予 Root。

模块“操作”菜单：

- **音量+**：通过兼容层在后台调用 KernelSU 自身的保存接口，补齐需要的挂载例外。
- **音量-**，或 8 秒不操作：查看诊断和最近结果。

辅助程序按实际安装的组件及当前 UID 生成名单，合并共享 UID，跳过纯资源 Overlay。它会保留全局默认、已有 Root 授权和无关配置；已有例外会跳过。接口不匹配、应用 UID 或配置并发变化时停止，并报告已完成项；不会自动重启，也不会设置 LSPosed。

后台配置需要兼容层的 KernelSU 作用域，按管理器实际提供的接口、身份和配置结构判断兼容性，不绑定固定版本号、内核 UAPI 版本或 APK 构建哈希。通过管理器已有的不导出 Provider 直连，避免系统缓存后台广播。保存前先只读预检，保存后回读并等待磁盘记录确认；异步落盘最多等待 30 秒，必要时发送本模块的临时系统属性事件唤醒保存。没有通过确认就停止后续项，不会把“任务已启动”当作“全部补齐”。不支持的接口或配置结构会停止。管理器在任务期间若发生更新也会停止，请重新运行。不会直接改写 KernelSU 配置文件，不依赖界面语言、样式或屏幕尺寸。旧界面辅助方式仍保留为 `ksu-mount.sh --apply-ui`，该方式仅支持原先核对过的 KernelSU 3.3.0 构建、中文 Material 界面、屏幕尺寸和解锁状态。

## 兼容层能做什么

兼容层主界面提供国行搜索、天气、主题、黄页、电话和短信兼容开关，以及运行状态检查和应用维护入口。

- 模块安装选项在界面中显示为状态；要调整这些选项，需要修改安装配置并重新安装模块。
- 应用兼容开关修改后，重新打开对应应用；涉及电话或首次启用作用域时完整重启。
- 实验性地区开关默认关闭；兼容层不会替你选择隐私同意或权限。
- 维护工具中的清理操作需要 Root 授权，由你选择并确认，默认不选择清理项。

## 卸载与恢复

在 KernelSU 卸载模块后完整重启。模块卸载脚本不主动清除应用数据，但系统在移除或切换系统应用时仍可能处理相关数据，重要内容请先备份。独立安装的 APK、手动安装的应用更新和手动调整的 Root 设置需要分别管理。

如果无法进入系统，可在 Recovery 中停用模块，再启动系统。模块目录为 `/data/adb/modules/HyperOS_EU2CN`，停用方式是在该目录创建空的 `disable` 文件；不要清除或格式化数据。

## 命名与反馈

项目名、模块名称和兼容层名称统一为 **HyperOS_EU2CN**。模块 ID 为 `HyperOS_EU2CN`，配置文件名为 `EU2CN_Config.ini`。兼容层 APK 包名、签名、偏好文件及模块内 APK 路径保留。

反馈时请附上机型、ROM 版本、模块版本、Root / LSPosed 环境、出问题的功能和复现步骤。模块“操作”的诊断结果可辅助定位；请先移除账号、通知等个人内容。
