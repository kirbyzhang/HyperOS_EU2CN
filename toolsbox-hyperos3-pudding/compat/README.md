# HyperOS_EU2CN 兼容层

版本：OS318.0.1；内部版本号：31801。

这是与 HyperOS_EU2CN 模块配合使用的 LSPosed 兼容层。用户可以管理国行搜索、天气、主题、黄页、电话和短信等兼容开关，查看运行状态，并按需使用维护工具。

推荐作用域新增 KernelSU。从模块“操作”入口按音量+时，兼容层可在管理器进程内保存挂载例外，无需亮屏或逐页点击；只响应模块显式请求，不自行在开机时修改配置，不授予 Root。

完整模块已包含同一 APK。独立发行文件为 `HyperOS_EU2CN_Compat_OS318.0.1.apk`。安装后需在 LSPosed 中启用并选择推荐作用域，再完整重启。

应用包名仍为 `local.pudding.weathercompat`，沿用原签名、偏好文件和作用域标识。发布标签与应用显示名称已统一；旧工具箱不另行打包。

详细安装方法、功能范围和验证限制见项目根目录 README。
